## 新实验配置与启动

新配置保留 961 物种、每物种 1000 训练窗口、10 epochs、seed42、batch4、累积8 和原损失权重。变化是训练启用 U（guidance_dropout=0），P 关闭；验证及选最佳模型仍使用纯 DNA。实验目录与原纯 DNA 基线分开。尚未证明该配置能提高准确率。

确认空闲 GPU 后，手动启动（本次适配不自动启动模型训练）：

```bash
if [ -e runs/bacteria_species961_train1000_uonly_seed42_v1_finetune ]; then
  echo '实验目录已存在，请换新 experiment-name，避免覆盖'
else
  CUDA_VISIBLE_DEVICES=0 nohup python -u scripts/finetune.py \
    --config configs/finetune_species961_train1000_uonly_seed42.yaml \
    --pretrained runs/bacteria_species_cls_v1_pretrain_v2/best_model.pt \
    --gpus 0 > tests/data/finetune_species961_uonly.log 2>&1 < /dev/null &
fi
```

评估该模型时用 `--input-mode sequence_only`。compact 得分只覆盖 train，程序会拒绝在 val/test 中启用得分。更改机器路径时只改 YAML 中的数据路径，不修改原 pickle；读取器根据原始内部 ID 和窗口起点映射得分，不使用旧机器的 SequenceInfo.fna_file 路径。

`train_row_offsets.npy` 内是绝对 float32 元素偏移，不能再加 window_start，也不要填写到原 scores_bin_file 字段；只设置 compact_scores_dir。
